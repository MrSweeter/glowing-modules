search

Plain words of 3 or more characters are regular expressions matched against module names. Use repository: or owner: to filter repositories, name: to keep only matching module names and -name: to hide them.

Search syntax

  • account: module names containing "account" (case-insensitive, 3+ characters)
  • ^l10n_(be|lu)_: regular expressions work
  • account edi: several words must all match
  • repository:enterprise (or repo:): only that repository; several are combined with OR
  • owner:odoo: only repositories of that owner
  • name:^pos_: only module names matching; several are combined with OR
  • -name:^l10n_: hide module names matching
